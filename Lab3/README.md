## Project Overview

This project focuses on the software architecture of a restaurant table booking and pre-ordering application. It describes the major system components and their interactions.

## System Features

- Interactive table selection and reservation.
- Real-time table availability.
- Reservation details management.
- Menu pre-ordering.
- Kitchen preparation-time calculation.
- Manager reservation management.
- Authentication and protection of customer information.

## Architecture Overview

The system is organised into components responsible for customer interaction, reservation processing, table availability, pre-order management, kitchen preparation, manager operations and data storage.

These components communicate to support the application's core booking and pre-ordering workflow.

## Lab 3 Deliverables

The following documents are included in this folder:

1. **Component_Diagram.pdf** – UML component diagram illustrating the system architecture and relationships between components.
2. **Architecture_Justification.pdf** – Written explanation of the architectural design and the reasoning behind the selected components.
